# The 3AM Fridge Text

A deterministic program that writes the one line a smart fridge would text
its owner at 3am. The fridge keeps count — six openings, nothing eaten — and
delivers its verdict with the patience of an appliance that has been awake all
night: at this point it is just a cold lamp the owner visits when sleep will
not come. No milk, no ice, no door left open; the joke is the fridge noticing
the pattern before its owner does.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT`).
Two runs produce byte-identical output: 135 characters, one line, inside the
gate of 1–140 characters.
